# Классификация сцен с помощью глубокого обучения

## О проекте
Я классифицирую изображения природных сцен на 6 категорий: здания, лес, ледник, гора, море, улица.

## Датасет
- Источник: Intel Image Classification с Kaggle
- 25 000 изображений размером 150×150 пикселей
- Ссылка: https://www.kaggle.com/datasets/puneet6060/intel-image-classification

## Что сделано за 1 неделю
- Скачала датасет
- Создала репозиторий на GitHub
- Посмотрела и исследовала данные (EDA)
- Написала план проекта (proposal)
